# Web Dev - Chapter 8

ตามที่ได้เลือกโครงสร้างแบบแยก 2 โฟลเดอร์:
- **Backend**: [`../web-dev-CH-8-backend`](../web-dev-CH-8-backend) (Express.js, MySQL, JWT Auth, Rating & User Management)

### วิธีเริ่มใช้งาน

   ```bash
   cd ../web-dev-CH-8-backend
   npm run dev
   ```

2. รัน Frontend:
   ```bash
   cd ../web-dev-CH-8-frontend
   npm run dev
   ```
